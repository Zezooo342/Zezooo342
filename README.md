نظام احترافي متكامل لإدارة صفحات فيسبوك وإنستغرام وتيك توك ويوتيوب مع توليد محتوى ذكي جاهز للنشر.

## 🌟 المميزات الرئيسية

### 🧠 **ذكاء اصطناعي متقدم**
- مدعوم بـ **Perplexity Pro AI** للحصول على أحدث المعلومات
- توليد محتوى أصلي 100% مخصص لكل منصة
- تحليل الترندات الحية والموضوعات الرائجة

### 📱 **دعم شامل لجميع المنصات**
- **📘 فيسبوك**: منشورات تفاعلية طويلة مع دعوات للعمل
- **📸 إنستغرام**: محتوى بصري جذاب مع هاشتاجات محسنة
- **🎵 تيك توك**: فيديوهات قصيرة تتبع أحدث الترندات  
- **📺 يوتيوب**: محتوى تعليمي مع تحسين للسيو

### 💰 **استراتيجيات ربح مدروسة**
- خطط تحقيق دخل مخصصة حسب عدد المتابعين
- حاسبات أرباح متوقعة لكل منصة
- نصائح عملية لزيادة الدخل تدريجياً

### 🎯 **سهولة الاستخدام**
- **لوحة نشر تفاعلية**: نسخ المحتوى بضغطة واحدة
- **محتوى جاهز للنشر**: لا حاجة لتعديل أو إعادة كتابة
- **أوقات نشر محسنة**: لكل منصة حسب الجمهور

## 🚀 البداية السريعة

### 1️⃣ **إنشاء المستودع**
```bash
# استنسخ المستودع
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
cd YOUR_REPO_NAME

# أو أنشئ مستودع جديد وأضف الملفات
```

### 2️⃣ **إعداد الملفات الأساسية** 
أضف هذه الملفات لمستودعك:

- `smart_page_creator.py` - النظام الرئيسي
- `requirements.txt` - المكتبات المطلوبة  
- `.github/workflows/smart_page_creator.yml` - سكريبت GitHub Actions
- `README.md` - هذا الملف

### 3️⃣ **تفعيل GitHub Actions**
1. اذهب إلى **Settings** في مستودعك
2. **Actions** → **General** → تأكد من تفعيل Actions
3. **Pages** → **Source** → اختر "GitHub Actions"

### 4️⃣ **إضافة Perplexity Pro API (اختياري)**
1. احصل على API key من [perplexity.ai](https://perplexity.ai/settings/api)
2. **Settings** → **Secrets and variables** → **Actions** 
3. **New repository secret**:
   - **Name**: `PERPLEXITY_API_KEY`
   - **Secret**: مفتاح الـ API الخاص بك

### 5️⃣ **تشغيل النظام**
- اذهب إلى **Actions** في مستودعك
- انقر **"Smart Page Creator"**
- **Run workflow** → **Run workflow**
- انتظر 3-5 دقائق للحصول على النتائج
